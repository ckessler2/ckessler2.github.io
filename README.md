# ckessler2.github.io

Personal academic site, hosted with GitHub Pages: https://ckessler2.github.io/

All pages are static HTML, CSS and JavaScript, with no build step. The MATLAB files are reference versions of the models, not used by the site.

| Page | What it is | Languages |
| --- | --- | --- |
| [Homepage](https://ckessler2.github.io/) (`index.html`) | Bio, publications, proceedings and talks | HTML, CSS |
| [Photography](https://ckessler2.github.io/photography.html) (`photography.html`) | Photo gallery; images are stored in `photos/` | HTML, CSS |
| [Plate model](https://ckessler2.github.io/plate-model/) (`plate-model/`) | 2D quasi-steady falling plate simulator: tune nondimensional parameters, plot the trajectory and state variables over time, export CSV/SVG | JavaScript, HTML, CSS (MATLAB reference) |
| [Dandidrone generator](https://ckessler2.github.io/dandidrone-generator/) (`dandidrone-generator/`) | Generates a dandelion-inspired filament outline from a diameter, filament width and count, with DXF/SVG export | JavaScript, HTML, CSS (MATLAB reference) |

Other folders: `figures/` holds publication thumbnails and the background image, and `PDFs/` holds talk slides.
